#  AAU Study Buddy Bot (Under Development)

AAU Study Buddy Bot is a Discord bot designed to help students stay focused, organized, and motivated during university life — especially at Aalborg University (AAU).

This project is currently **under active development**, and new features are being added step by step.

---
##  Project Vision

The goal is to build a modern Discord study assistant that combines:

- Productivity tools (Pomodoro + reminders)
- Daily programming questions (C / Discrete Math)
- Study statistics and streak tracking
- A clean command-based architecture

This bot is meant to be both useful for real student servers and a strong portfolio project.
